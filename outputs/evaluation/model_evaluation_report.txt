1. INTENT DETECTION
-------------------
  Model           : TF-IDF Vectorizer + Logistic Regression
  Dataset Size    : 251 labelled instructions
  Languages       : English, Hindi, Hinglish
  Train / Test    : 80% / 20%  (201 train, 50 test)
  Accuracy        : 82.93%
  Macro F1        : 0.82
  Weighted F1     : 0.82

  Intents covered (14):
    ADD_CUSTOMER, UPDATE_CUSTOMER, DELETE_CUSTOMER,
    UPDATE_PRODUCT, UPDATE_EMPLOYEE, DELETE_EMPLOYEE,
    DOWNLOAD_REPORT, UPLOAD_FILE, READ_TABLE, SEND_EMAIL,
    FILL_FORM, OPEN_PAGE, CLICK_BUTTON, TAKE_SCREENSHOT

  Notes:
  - FILL_FORM, TAKE_SCREENSHOT, UPDATE_PRODUCT, UPLOAD_FILE
    achieved F1 = 1.00
  - ADD_CUSTOMER F1 = 0.76 (highest frequency class)
  - CLICK_BUTTON F1 = 0.50 (low support: 3 samples)
  - Increasing dataset size will improve low-support classes

    Price (₹/Rs/INR)   Accuracy : 100%
