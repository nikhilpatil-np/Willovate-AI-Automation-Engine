How to run:
Terminal 1 — CRM Backend (SQLite API on port 8001)
  cd c:\willovate\Willovate-AI-Automation-Engine
  .\.venv\Scripts\activate
  uvicorn app.services.crm_service:app --port 8001 --reload

Terminal 2 — Main AI Engine + Frontend (port 8000)
  cd c:\willovate\Willovate-AI-Automation-Engine
  .\.venv\Scripts\activate
  uvicorn main:app --port 8000 --reload
