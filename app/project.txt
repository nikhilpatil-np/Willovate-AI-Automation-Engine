Project: Willovate AI Automation Engine
Main Goal
Build an AI system that understands a user’s instruction and converts it into an automation workflow
that can be executed on any web application.
Take reference from UiPath for understanding workflows, automation activities and bots.
Example:
User instruction:
“Open the customer page, add Rahul with phone number 9876543210 and save.”
